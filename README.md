# 🎯 Guess the Number Game

A simple and fun **Guess the Number** game built using **HTML, CSS, and JavaScript**. Test your guessing skills by trying to guess the randomly generated number!

## 📌 About the Project

Guess the Number is an interactive browser-based game where the computer generates a random number, and the player has to guess it correctly.

With every guess, the game provides feedback to help the player figure out the correct number.

## 🛠️ Technologies Used

- **HTML5** – For creating the structure of the game.
- **CSS3** – For styling and designing the user interface.
- **JavaScript** – For game logic, random number generation, and user interactions.

## 🎮 Features

- Random number generation.
- Interactive user interface.
- Instant feedback on guesses.
- Displays whether the guess is too high or too low.
- Simple and user-friendly design.
- Fun and engaging gameplay.
